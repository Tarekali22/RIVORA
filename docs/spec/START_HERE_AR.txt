RIVORA — ابدأ من هنا

ما ستنزله:
- RIVORA_CLOUD_PACKAGE.zip فقط. لا تحتاج إلى تثبيت Unreal أو Unity أو Blender أو Node أو Git على الكمبيوتر.

محتويات الحزمة:
- RIVORA_MASTER_PROMPT_EN.txt: البرومبت الكامل بالإنجليزية، ويشمل التعليمات الجديدة وسياسة التنفيذ السحابي.
- EXECUTION_MODE_OVERRIDE_EN.txt: قواعد التشغيل السحابي واستخدام OpenArt والبدائل المجانية والصور الشخصية. تم تضمينه أيضًا في بداية البرومبت الكامل.
- Reference_Images/: الصور المرجعية التي أرسلتها عن شكل اللعبة والمشاهد.
- Player_Photos/: مجلد فارغ مخصص لصورك الشخصية، لأنك لم ترسل صورًا شخصية واضحة بعد.

ما الذي تحتاجه؟
1. افتح Claude Code على الويب: https://claude.ai/code
2. إذا ظهرت لك ميزة Cloud sessions، اربط GitHub مرة واحدة واختر مستودعًا خاصًا باسم rivora-game. لا تثبت أي برنامج على الكمبيوتر.
3. ارفع RIVORA_CLOUD_PACKAGE.zip إلى مستودع GitHub الخاص بالمشروع من المتصفح، أو أرفق ملفات الحزمة في جلسة Claude إذا أتاحت الجلسة رفع الملفات مباشرة.
4. تأكد أن موصل OpenArt البعيد Remote MCP ظاهر في Claude. إذا كان الذي ربطته إضافة محلية تعمل داخل Desktop فقط، فقد لا يظهر في جلسة Cloud. لا تعِد الربط إلا إذا أكد Claude أنه غير متاح.
5. أرسل إلى Claude الرسالة الموجودة في SEND_TO_CLAUDE_EN.txt.
6. عندما تصل لخطوة إنشاء وجه البطل، أضف 3 إلى 5 صور واضحة لك داخل Player_Photos أو أرفقها مباشرة في Claude.

مهم:
- Claude Code Cloud يحتاج خطة Claude مؤهلة، واتصال GitHub. لا يحتاج تثبيت Claude Code CLI أو محرك ألعاب على جهازك.
- GitHub هنا لحفظ ملفات المصدر والعمل السحابي فقط؛ لا يعني نشر اللعبة على موقع آخر. تجربة اللعب النهائية مطلوبة داخل Claude Artifact.
- إن لم تظهر Cloud sessions في حسابك، لا تثبت أدوات محلية. استخدم Claude Artifacts مباشرة، مع العلم أن الأتمتة والتحكم بالملفات قد تكون أقل.
- Three.js أو Babylon.js (إذا كانا مدعومين) هما محرك/إطار الرسوم ثلاثية الأبعاد داخل المتصفح. لا تحتاج Unreal أو Unity لتشغيل Artifact.
- OpenArt يستهلك أرصدة الحساب. يجب أن يفحص Claude الرصيد ويستخدم المجاني/المتاح فقط. لا تسمح له بشراء أرصدة.
- ChatGPT ليس أداة يمكن لـClaude استدعاؤها تلقائيًا من دون تكامل فعلي. يمكنه استخدام نموذج GPT Image عبر OpenArt فقط إذا كان ظاهرًا ومتاحًا، مع فحص التكلفة. وإلا يستخدم البدائل المجانية.
- لم أضع صورك الشخصية لأن الصور المرفقة سابقًا هي لقطات مرجعية من لعبة وليست صورًا شخصية موثقة لك. أضف صورك بنفسك عند تجهيزها.
- لا تشارك صورك الشخصية أو مجلد Player_Photos داخل Artifact العام. استخدمها لبناء نموذج الشخصية فقط ثم لا تضع ملفات المصدر الخاصة بها في النسخة المنشورة.
