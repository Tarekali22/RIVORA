For this delivery target, do NOT install or require Unreal Engine or Unity locally. A traditional native AAA engine is incompatible with the user's no-install, browser-only requirement.

Build a browser-native 3D game using the best runtime that Claude Artifacts actually supports. Prefer Three.js, React Three Fiber, Babylon.js, or another compatible WebGL/WebGPU framework if available and permitted. Treat the selected browser 3D framework as the game's runtime engine. If a dependency cannot be loaded or bundled inside the Artifact, implement the closest self-contained WebGL/Canvas fallback and document the limitation.

First inspect the actual Artifact runtime, supported packages, asset handling, file limits, persistence, browser APIs, and mobile input support. Never assume a library, package manager, network request, filesystem API, or GPU feature is available until verified.

The Artifact must contain the playable game logic and packaged game assets. The game must not require every player to connect OpenArt, ElevenLabs, ChatGPT, or another external account.
